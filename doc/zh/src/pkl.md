# Pkl

Pkl is a configuration language that allows you to define and generate configuration files in various formats. It is designed to be expressive, scalable, and safe, enabling developers to manage complex configurations with ease.

Pkl is used for defining configurations for applications, services, and infrastructure. It supports features like modules, classes, and functions, allowing for modular and reusable configuration definitions.

The mdbook-lang preprocessor for Pkl allows you to embed and execute Pkl code directly within your book. The preprocessor uses the `pkl eval` command to evaluate your code and display the output.

```pkl
// This is an example of a Pkl code block.
key = "value"
```
